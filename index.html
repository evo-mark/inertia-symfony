Build single-page apps with Vue, React or Svelte, using Symfony controllers and routing.

Configuration

  • Controllers, not an API

    Return `$inertia->render('Component', $props)` from any controller and keep Symfony's routing, security and forms.

  • Every Inertia prop type

    Shared, optional, deferred, merge, once, always and scroll props, with partial reloads handled for you.

  • Server-side rendering

    Render pages on a Node SSR server with automatic fallback, failure events and an opt-in exception.

  • Symfony native

    Autowired services, attribute-registered listeners, session flash and validation errors, and a Twig root template.
